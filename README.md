# BrawlFishing

BrawlFishing is an Unreal Engine multiplayer party-game prototype. The project is intended to support 4–8 players and currently contains the Unreal project and its C++ game module.

## Prerequisites

Install the following before building locally:

- Git
- Unreal Engine version associated with `BrawlFishing.uproject`
- Visual Studio Community 2026 with the **Game development with C++** workload
- The Visual Studio components recommended by Unreal Engine, including Windows SDK and MSVC build tools

The project currently uses Unreal Engine 5.8 target settings. If Unreal reports that the project was created with another engine version, use the version configured for the project or upgrade it deliberately through Unreal Editor.

## Clone the repository

From PowerShell:

```powershell
git clone https://github.com/DaltonGorham/BrawlFishing.git
cd BrawlFishing
```

To work on a separate branch:

```powershell
git switch -c feature/my-change
```

## Open the project in Unreal Engine

Open `BrawlFishing.uproject` from File Explorer or from the Unreal Project Browser.

Unreal is the main project environment. Use it to:

- Open and edit maps and levels
- Import and modify character, environment, and other assets
- Create and edit Blueprints
- Configure project settings and plugins
- Play the game in the Editor
- Package the game

The `Content/` directory contains Unreal assets. These assets are edited in Unreal Editor and should not be edited as ordinary Visual Studio files.

## Generate the Visual Studio project

The Visual Studio solution is generated by Unreal and is intentionally ignored by Git. Do not expect the generated `.sln` or `.slnx` file to be available immediately after cloning.

To generate it:

1. Close Unreal Editor if it is open.
2. Right-click `BrawlFishing.uproject`.
3. Select **Generate Visual Studio project files**.
4. Open the generated `BrawlFishing.sln` or `BrawlFishing.slnx` in Visual Studio.

If the right-click option is unavailable, open the project in Unreal Editor and use **Tools > Refresh Visual Studio Project** when available, or run the project-file generation command from the installed Unreal Engine tools.

## Build the C++ code in Visual Studio

1. Open the generated solution.
2. Set the configuration to **Development Editor**.
3. Set the platform to **Win64**.
4. Select `BrawlFishingEditor` as the startup project if Visual Studio has not selected it automatically.
5. Build the solution with **Build > Build Solution**.

For normal gameplay development, build the editor target rather than the entire Unreal Engine solution. The relevant project source is under:

```text
Source/BrawlFishing/
```

The Unreal Build Tool reads the module rules from `Source/BrawlFishing/BrawlFishing.Build.cs` and the target definitions from:

```text
Source/BrawlFishing.Target.cs
Source/BrawlFishingEditor.Target.cs
```

## How Visual Studio links to Unreal

Visual Studio does not run this project as an independent .NET application. It compiles the Unreal C++ module through UnrealBuildTool and produces binaries that Unreal Editor loads.

The relationship is:

1. `BrawlFishing.uproject` identifies the Unreal project and its `BrawlFishing` module.
2. `Source/BrawlFishing/BrawlFishing.Build.cs` declares the module's Unreal dependencies.
3. `Source/BrawlFishing.Target.cs` defines the packaged/game target.
4. `Source/BrawlFishingEditor.Target.cs` defines the editor target used for development.
5. UnrealBuildTool generates the Visual Studio projects and controls the build.
6. Visual Studio compiles the C++ source files.
7. Unreal Editor loads the resulting editor module and exposes the C++ classes to the project and Blueprints.

After changing C++ headers, source files, build rules, target files, or plugins, rebuild in Visual Studio. After changing only assets or Blueprints, use Unreal Editor and compile the Blueprint there.

## Typical development loop

1. Open `BrawlFishing.uproject` in Unreal Editor.
2. Make asset, level, or Blueprint changes in Unreal.
3. Make C++ changes under `Source/BrawlFishing/` in Visual Studio.
4. Build **Development Editor | Win64** in Visual Studio after C++ changes.
5. Return to Unreal Editor and let it reload the updated module if prompted.
6. Press **Play** in Unreal Editor to test.
7. Commit source files and Unreal assets that belong in the repository. Do not commit generated build folders or generated Visual Studio solution files.

## Important generated folders

The following are generated locally and are ignored by Git:

- `Binaries/`
- `DerivedDataCache/`
- `Intermediate/`
- `Saved/`
- `.vs/`
- Generated `.sln` and `.slnx` files

If generated files become stale, close Unreal Editor and Visual Studio, remove `Binaries/`, `Intermediate/`, and `.vs/`, regenerate the Visual Studio project files, and build again.

## Current multiplayer direction

The planned MVP is a listen-server prototype: one player's game hosts the authoritative Unreal server while other players join it. Steam Online Subsystem integration can be added later for Steam sessions, discovery, and internet connectivity. It is not currently enabled by `BrawlFishing.uproject`.
